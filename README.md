# 🐾 PetTopia

Aplicação Android desenvolvida durante o curso Técnico em Informática da FAETEC, com foco na adoção e proteção de animais.

## 📱 Sobre o projeto

O PetTopia foi desenvolvido com o objetivo de facilitar a interação entre usuários e animais disponíveis para adoção, além de oferecer recursos relacionados à proteção e denúncia de situações de abandono e violência.

## 🚀 Funcionalidades

- Cadastro e autenticação de usuários
- Recuperação de senha
- Cadastro e gerenciamento de animais
- Adoção de animais
- Envio de documentos
- Registro de denúncias de abandono e violência
- Consulta e preenchimento de endereços por meio da API ViaCEP

## 🛠️ Tecnologias utilizadas

- **Kotlin**
- **Android**
- **AndroidX**
- **Retrofit**
- **OkHttp**
- **Gson**
- **ViewModel**
- **Repository**
- **ViaCEP API**

## 🏗️ Arquitetura

O projeto utiliza uma estrutura baseada em **ViewModel** e **Repository**, buscando separar responsabilidades e organizar o código da aplicação.

A comunicação com APIs é realizada utilizando **Retrofit** e **OkHttp**, enquanto o **Gson** é utilizado para o tratamento de dados em formato JSON.
